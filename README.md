An entry for the make.fun bounty
[One Line to Your Younger Self](https://make.fun/c/u-boothlord-one-line-to-your-younger-self-22e97f76):
the single line you would send your younger self if one line were all you got.

## Run

```sh
python3 main.py
```

The program checks its line against the gate (UTF-8 text of 1 to 200
characters, not only white space, a single line) and writes it to
`/output/entry.txt`.
